# bcrypt/passlib pitfall (documented for the journal): passlib's bcrypt
# backend probes `bcrypt.__about__.__version__`, which was REMOVED in
# bcrypt>=4.1, causing passlib to throw
# `AttributeError: module 'bcrypt' has no attribute '__about__'` at import/hash
# time (a known passlib 1.7.4 x bcrypt 4.1+ incompatibility). We avoid the
# whole class of bug by calling the `bcrypt` package directly (no passlib) and
# pinning bcrypt==4.0.1, the last release that still exposes `__about__`.
